# S3

List, copy, sync and share objects. `aws s3` is the high-level interface; paths look like `s3://<bucket>/<prefix>/`.

## Browsing

### List all buckets

```bash
aws s3 ls
```

### Count and size the objects under a prefix

```bash
aws s3 ls s3://<bucket>/<prefix>/ --recursive --human-readable --summarize
```

The last two lines of the output give the total object count and total size.

## Transferring

### Copy a local file to a bucket

```bash
aws s3 cp <file.txt> s3://<bucket>/<prefix>/
```

Swap the two arguments to download instead.

### Sync a local directory to a bucket

```bash
aws s3 sync <directory> s3://<bucket>/<prefix>/
```

Only new or changed files are uploaded. Add `--dryrun` first to preview the transfer.

### Generate a temporary download link

```bash
aws s3 presign s3://<bucket>/<key> --expires-in <seconds>
```

Anyone holding the URL can fetch the object until it expires; the default lifetime is one hour.

## Deleting

### ⚠ Sync a directory and delete extra files in the bucket

```bash
aws s3 sync <directory> s3://<bucket>/<prefix>/ --delete
```

!!! warning
    Objects under the destination prefix that do not exist in the source directory are deleted. Run with `--dryrun` first. On a versioned bucket the old versions remain recoverable; otherwise the data is gone.

### ⚠ Delete everything under a prefix

```bash
aws s3 rm s3://<bucket>/<prefix>/ --recursive
```

!!! warning
    Every object under the prefix is removed. Without versioning this cannot be undone; with versioning it only adds delete markers. Add `--dryrun` to list what would be deleted.

See also the official [AWS CLI v2 command reference](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/index.html).
